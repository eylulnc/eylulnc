### 📱 Featured Projects
 
#### **Notia — Kotlin Multiplatform**
 
A minimalist daily focus app, published on both Android and iOS.
 
* 📲 [Google Play](https://play.google.com/store/apps/details?id=com.eylulnc.notia&hl=en_US) · [App Store](https://apps.apple.com/app/notia-daily-focus/id6761326232)
* ⚙️ Shared domain and data layers using **Kotlin Multiplatform**
* 🧠 Streak logic, repository abstractions, and persistence in shared code
* 🧪 Deterministic tests with fake providers for business logic
* 🤖 Native Android UI with **Jetpack Compose**
* 🍏 Native iOS UI with **SwiftUI**
* 🔄 Shared business logic while maintaining platform-specific UX

#### **NextRole — Full Stack**
 
A full-stack job application tracker built around a real application pipeline rather than a simple CRUD dashboard.
 
* ⚛️ Frontend: **React + TypeScript**
* ☕ Backend: **Kotlin + Spring Boot**
* 🐘 Database: **PostgreSQL + Flyway**
* 🔐 Authentication with **JWT & Spring Security**
* 🐳 Docker & Docker Compose
* 🧪 Backend and frontend testing with **JUnit, MockK, Vitest & React Testing Library**
* 📊 Dashboard, analytics, calendar, interviews, contacts, notes, and application tracking
* 🔄 Built with a focus on maintainable architecture and a complete end-to-end product experience

#### **Aura — Mood Journal (Android & iOS)**
 
A minimal, thoughtful mood tracking app. Log how you're feeling each day, track patterns over time, and see emotional trends at a glance — with separate native implementations per platform.
 
* 📲 [App Store](https://apps.apple.com/app/aura-mood-tracker/id6789640136) · [Google Play](https://play.google.com/store/apps/details?id=com.github.eylulnc.aura)
* 🎯 Daily mood logging via a 13-step slider, with an optional note per entry
* 📊 Home dashboard: streak, days logged this month, top mood, weekly positive %, 7-day trend chart
* 📅 History calendar with colour-coded entries and a scrollable list
* 🎨 Full light/dark theming, including dedicated mood icon variants per theme
* 🔐 Optional Google sign-in with Firestore sync; fully offline-first guest mode otherwise
* 📱 Home screen widgets on both platforms (WidgetKit on iOS, Jetpack Glance on Android) and daily reminder notifications

#### **Walk Munich — Android**
 
A mobile app for exploring Munich through curated walking routes.
 
* 🗺️ Route and place-based itineraries
* 📍 Local JSON data for offline use
* 🎨 **Jetpack Compose**
* 🧭 **Navigation 3**
